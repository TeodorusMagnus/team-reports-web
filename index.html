Как получить токен
  1. Откройте создание токена на GitHub.
  2. Название — например, «Отчёты команды»; срок — на ваше усмотрение.
  3. Repository access → Only select repositories → выберите репозиторий с отчётами.
  4. Permissions → Contents → Read-only; Issues → Read and write (для задач).
  5. Нажмите Generate token, скопируйте его и вставьте сюда.

Токен хранится на этом компьютере в зашифрованном виде (Windows DPAPI).

Ключ Владыки

Новый ключ показан один раз. Он уже подставлен в поле выше и сохранится кнопкой «Сохранить».

Не отправляйте ключ в чат, почту или Telegram — вводите его на других устройствах и в GitHub вручную.

Зачем ключ и как его настроить

Ключ подписывает ваши задачи и ответы. Агенты выполняют только подписанное: задачи, созданные чужим токеном, помечаются как гостевые и агентам не передаются.

  1. Создайте ключ здесь, в Windows-версии, и нажмите «Сохранить».
  2. Откройте репозиторий на GitHub → Settings → Secrets and variables → Actions, нажмите New repository secret, имя OWNER_KEY, значение — ключ.
  3. Введите тот же ключ на телефоне и в веб-версии (поле «Ввести ключ»).

Никогда не пересылайте ключ через чат, почту или Telegram и не давайте его друзьям: у них свои токены без ключа. Если ключ мог утечь — создайте новый, замените секрет и введите его заново на всех устройствах.
